## 6. T3.9 桌面端 GUI 走查（`scripts/walkthrough-desktop.mts`，CDP 驱动构建产物）

延续 M2 场景 5 的走查口径（构建产物 electron.exe 直启 + `--remote-debugging-port`），种子临时 RAINCODE_HOME（生态形态 mcp.json 指向 stdio fixture / 示例插件 hello / 官方示例技能 ×3 / config.json Provider——apiKeyRef null 无凭据，假 key 不落任何文件）。**14 断言全过**：

- **A 扩展面板**：MCP server Connected 投影 + 健康检查 RTT 实测呈现 + 插件停用→已停用→再启用→已激活 + MCP server 停用→未连接→再启用→已连接（受理即返 + `mcp.server_status_changed` 事件活更路径）。
- **B 斜杠命令面板**：`/` 唤起 workspace 层技能清单、↑↓ + Tab 键盘补全（CDP Input 真实键事件）、Enter 走 skills.invoke 端到端回合（server 侧展开）。
- **C 用量统计**：回合收束后侧栏 ↑/↓ token 行呈现（done → session.usage 刷新）。
- **D 记忆管理器**：MR-4 三栏视图可达（M2 未覆盖界面的人工走查项自动化替代）。

**走查发现并修复 3 缺陷**（详见 PROGRESS §4）：

1. **生态形态 mcp.json 被拒载**：文档与 README 口径的 `{"mcpServers": {"<key>": {...}}}`（serverKey 由 map 键承载）被 `mcpServerConfigSchema` 判缺 `serverKey` 字段 → MCP_CONFIG_INVALID；smoke 一直写冗余字段从未暴露。修复：loadFile 按 map 键注入 serverKey，显式字段仅一致性校验（packages/mcp/test/config.test.ts 六用例锁定）。
2. **损坏 mcp.json 崩掉 agent（崩溃循环放弃）**：`McpRuntime.init()` 抛 MCP_CONFIG_INVALID 经 fire-and-forget `void init()` 成为未处理拒绝 → agent 子进程崩溃 → 桌面守护 5 次放弃。修复：init 失败降级为 stderr 诊断 + mcp 域空转（packages/server/test/mcp-degrade.test.ts 锁定）。
3. **斜杠面板吞 Enter**：面板打开且已输入参数时，palette 分支 `return` 拦截了发送路径——真实用户输参后按 Enter 无反应。修复：有参 Enter 落回正常发送分支。

另修复面板数据陈旧：拉取早于域就绪时状态事件对未知行不可增量补 → reducer 增加 `extensionsTick` 通道，事件到达驱动面板重拉全量。
