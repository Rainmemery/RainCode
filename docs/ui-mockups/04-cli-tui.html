⚠权限审批交互

审批块以琥珀边框内嵌于消息流，Agent 同步暂停。决策方式：1–4 直选、y/n 快捷、Esc 拒绝。决策后块折叠为单行结果；「始终允许」自动写入桌面端权限规则，双端语义一致。

⚙行内状态语义

工具行：✓ 成功 · ⟳ 运行中（spinner） · ✗ 失败 · ⚠ 待审批。徽标：〔沙箱〕本地沙箱执行、〔MCP·名〕远程调用、⧉ 子代理块。生成中行尾为橙色闪烁光标。
